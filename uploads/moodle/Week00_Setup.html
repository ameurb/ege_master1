Read before Week 1  |  Master 1 — Python & Data Analysis for Economics

Overview / نظرة عامة

This guide helps you set up your Python environment before Week 1. You have two options: Google Colab (recommended, no installation needed) or a local Jupyter installation via Anaconda.

هذا الدليل يساعدك على إعداد بيئة Python قبل الأسبوع الأول. لديك خياران: Google Colab (موصى به، لا يحتاج تثبيتاً) أو تثبيت Jupyter محلياً عبر Anaconda.

Option A Google Colab (Recommended / موصى به)

Google Colab Recommended

Free, runs in your browser, no installation. All required libraries (pandas, matplotlib, seaborn, statsmodels, scikit-learn) are pre-installed.

مجاني، يعمل في المتصفح، بدون تثبيت. جميع المكتبات المطلوبة مثبّتة مسبقاً.
Go to colab.research.google.com — sign in with your Google account / اذهب إلى colab.research.google.com وسجّل الدخول بحسابك على Google
Click File → Upload notebook and select the .ipynb file downloaded from Moodle / انقر File ثم Upload notebook واختر ملف .ipynb المحمّل من Moodle
Upload the CSV dataset: click the folder icon in the left sidebar → Upload → select algeria_economic_combined.csv / ارفع ملف CSV: انقر أيقونة المجلد في الشريط الجانبي ← Upload
Run cells with Ctrl+Enter (current cell) or Shift+Enter (run and move to next) / شغّل الخلايا بـ Ctrl+Enter أو Shift+Enter
Save your work: File → Save a copy in Drive to keep your changes / احفظ عملك: File ← Save a copy in Drive

Option B Local Installation via Anaconda
Download Anaconda from anaconda.com/download — choose Python 3.11, your OS (Windows/Mac/Linux) / حمّل Anaconda واختر Python 3.11 ونظام تشغيلك
Install Anaconda (keep all default options) / ثبّت Anaconda مع الإعدادات الافتراضية
Open Anaconda Navigator → click Launch under Jupyter Notebook / افتح Anaconda Navigator ثم انقر Launch تحت Jupyter Notebook
Navigate to your project folder and open the .ipynb file / انتقل إلى مجلد مشروعك وافتح ملف .ipynb
Place the CSV files in the same folder as the notebook / ضع ملفات CSV في نفس المجلد مع الدفتر

Install Missing Libraries / تثبيت المكتبات المفقودة

Anaconda includes most libraries. If any are missing, open the Anaconda Prompt (Windows) or Terminal (Mac/Linux) and run:

pip install statsmodels scikit-learn seaborn

Common Errors / أخطاء شائعة
FileNotFoundError: algeria_economic_combined.csv
The CSV file is not in the same folder as your notebook. In Colab: upload it. Locally: copy it to the notebook directory. / ملف CSV ليس في نفس مجلد الدفتر.
ModuleNotFoundError: No module named 'statsmodels'
Run in a cell: !pip install statsmodels
NameError: name 'df' is not defined
You skipped a cell. Run all cells from top to bottom: Menu → Runtime → Run all / تخطّيت خلية. شغّل كل الخلايا من البداية: Runtime → Run all
ValueError: could not convert string to float
A column contains text mixed with numbers. Check with df.dtypes and clean with pd.to_numeric(df['col'], errors='coerce')
KeyError: 'GDP_Growth'
Column name mismatch. Check exact column names with df.columns.tolist() — they are case-sensitive. / اسم العمود غير مطابق. تحقق بـ df.columns.tolist()
