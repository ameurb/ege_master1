Overview / نظرة عامة

This guide helps you set up your Python environment before Week 1. You have two options: Google Colab (recommended, no installation needed) or a local Jupyter installation via Anaconda.

يهدف هذا الدليل إلى مساعدتك على تهيئة بيئة العمل البرمجية قبل انطلاق الأسبوع الأول. لديك خياران: Google Colab (الخيار الموصى به، لا يستلزم تثبيتاً مسبقاً) أو تثبيت بيئة Jupyter محلياً عبر منصة Anaconda.
OptionPros / المزاياCons / العيوب
Google ColabNo install, free GPU, always up to date, runs in browserNeeds internet, files reset after session
Local JupyterWorks offline, files persist, full controlRequires installation (~3 GB), version management
Option A Google Colab (Recommended / موصى به)

Google Colab Recommended

Free, runs in your browser, no installation. All required libraries (pandas, matplotlib, seaborn, statsmodels, scikit-learn) are pre-installed.

مجاني ومتاح عبر المتصفح دون أي تثبيت مسبق. جميع المكتبات البرمجية المطلوبة (pandas, matplotlib, seaborn, statsmodels, scikit-learn) مُثبَّتة بشكل افتراضي في البيئة.
انتقل إلى colab.research.google.com وسجّل الدخول بحسابك على Google / Go to colab.research.google.com and sign in
انقر File → Upload notebook واختر ملف دفتر جوبيتر .ipynb الذي نزّلته من المنصة / Click File → Upload notebook and select the .ipynb file
ارفع ملف البيانات: انقر أيقونة المجلد في الشريط الجانبي → Upload → اختر algeria_economic_combined.csv / Upload the dataset via the folder icon in the sidebar
نفِّذ الخلايا البرمجية بـ Ctrl+Enter (الخلية الحالية) أو Shift+Enter (تنفيذ والانتقال للتالية) / Run cells with Ctrl+Enter or Shift+Enter
احفظ عملك: File → Save a copy in Drive للاحتفاظ بالتعديلات في Google Drive / Save your work via File → Save a copy in Drive

Common Errors / الأخطاء البرمجية الشائعة
FileNotFoundError: algeria_economic_combined.csv
ملف البيانات بصيغة CSV غير موجود في نفس مجلد دفتر جوبيتر. في Colab: أعد رفع الملف. محلياً: انسخ الملف إلى مجلد الدفتر. / The dataset file is not in the same folder as your notebook.
ModuleNotFoundError: No module named 'statsmodels'
المكتبة البرمجية غير مثبَّتة. نفِّذ في خلية جديدة: !pip install statsmodels / The library is not installed. Run in a new cell: !pip install statsmodels
NameError: name 'df' is not defined
تجاوزت خلية برمجية سابقة. نفِّذ جميع الخلايا من البداية: القائمة → Runtime → Run all / You skipped a cell. Run all cells from top to bottom: Menu → Runtime → Run all
ValueError: could not convert string to float
أحد الأعمدة يحتوي على نصوص مختلطة بأرقام. تحقق بـ df.dtypes وعالج بـ pd.to_numeric(df['col'], errors='coerce') / A column contains text mixed with numbers.
KeyError: 'GDP_Growth'
اسم العمود غير مطابق تماماً (الأسماء حساسة لحالة الأحرف). تحقق من الأسماء الدقيقة بـ df.columns.tolist() / Column name mismatch — names are case-sensitive. Check with df.columns.tolist()
