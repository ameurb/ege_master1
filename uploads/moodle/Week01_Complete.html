1. Variables / المتغيرات

A variable is a named container that stores a value. Variable names must start with a letter or underscore, contain no spaces, and cannot be a reserved keyword.

المتغير هو حاوية مُسمَّاة تخزن قيمة. يجب أن يبدأ اسم المتغير بحرف أو شرطة سفلية، لا يحتوي مسافات، ولا يكون كلمة محجوزة.
gdp_2024 = 25100        # int  — whole number / عدد صحيح
inflation_rate = 2.49   # float — decimal / عدد عشري
country = "Algeria"     # str  — text / نص
is_growing = True       # bool — True/False / قيمة منطقية

4. Economic Formulas / الصيغ الاقتصادية

GDP Growth Rate / معدل نمو الناتج المحلي

Growth (%) = ((GDP_new - GDP_old) / GDP_old) × 100
gdp_2023 = 24500
gdp_2024 = 25100
growth = ((gdp_2024 - gdp_2023) / gdp_2023) * 100
print(f"GDP Growth: {growth:.2f}%")   # → GDP Growth: 2.27%

Inflation Rate / معدل التضخم

Inflation (%) = ((CPI_new - CPI_old) / CPI_old) × 100
cpi_2023, cpi_2024 = 108.5, 111.2
inflation = ((cpi_2024 - cpi_2023) / cpi_2023) * 100
print(f"Inflation: {inflation:.2f}%")  # → Inflation: 2.49%

Compound Interest / الفائدة المركبة

A = P × (1 + r)^t
principal, rate, years = 100000, 0.05, 5
amount = principal * (1 + rate) ** years
print(f"Final: {amount:,.2f} DZD")    # → Final: 127,628.16 DZD

5. F-Strings / تنسيق النصوص

name = "Algeria"
gdp = 25100.5
pop = 46000000

print(f"Country: {name}")              # → Country: Algeria
print(f"GDP: {gdp:,.2f} B DZD")       # → GDP: 25,100.50 B DZD
print(f"Population: {pop:,}")          # → Population: 46,000,000
