1. Lists / القوائم

An ordered, mutable collection of values. Use for sequences of data (inflation series, GDP over years).

بنية بيانات مرتَّبة وقابلة للتعديل. تُستخدم لتخزين متتاليات البيانات الاقتصادية كسلاسل معدلات التضخم أو الناتج المحلي عبر السنوات.
inflation = [4.8, 6.4, 5.6, 4.3, 2.0, 9.2]   # list of floats

# Access / الوصول
print(inflation[0])      # → 4.8  (first / أول)
print(inflation[-1])     # → 9.2  (last / آخر)

# Operations / العمليات
inflation.append(5.5)    # add element / إضافة
len(inflation)           # → 7
sum(inflation)           # → 41.3
max(inflation)           # → 9.2
min(inflation)           # → 2.0
sorted(inflation)        # → [2.0, 4.3, 4.8, 5.5, 5.6, 6.4, 9.2]

2. Dictionaries / القواميس

Key-value pairs. Use for labeled data (country → GDP, indicator → value).

بنية بيانات تعتمد على أزواج مفتاح-قيمة. تُستخدم للبيانات المُصنَّفة كربط اسم الدولة بقيمة ناتجها المحلي أو المؤشر الاقتصادي بقيمته.
gdp = {"Algeria": 25100, "Morocco": 13200, "Tunisia": 4800}

# Access / الوصول
gdp["Algeria"]        # → 25100
gdp.keys()            # → dict_keys(['Algeria', 'Morocco', 'Tunisia'])
gdp.values()          # → dict_values([25100, 13200, 4800])
gdp.items()           # → pairs of (key, value)

# Add / إضافة
gdp["Egypt"] = 38000

# Loop / حلقة
for country, value in gdp.items():
    print(f"{country}: {value:,} B DZD")

3. For Loops / حلقات التكرار

تُستخدم حلقات التكرار لتطبيق عملية حسابية أو منطقية على كل عنصر في قائمة أو قاموس أو نطاق عددي.
# Loop over list
years = [2020, 2021, 2022, 2023, 2024]
for year in years:
    print(f"Year: {year}")

# Loop with range
for i in range(5):       # 0, 1, 2, 3, 4
    print(i)

# Loop over dict
for country, gdp_val in gdp.items():
    print(f"{country}: {gdp_val}")

4. Conditions / البنى الشرطية

تُستخدم البنى الشرطية لاتخاذ قرارات برمجية بناءً على قيمة متغير أو نتيجة تعبير منطقي.
growth_rate = 2.27   # Algeria 2024

if growth_rate > 5:
    print("Strong growth / نمو قوي")
elif growth_rate > 2:
    print("Moderate growth / نمو معتدل")
elif growth_rate > 0:
    print("Slow growth / نمو بطيء")
else:
    print("Recession / ركود")

5. Combining: Loop + Condition / دمج حلقة التكرار مع البنية الشرطية

countries = {"Algeria": 2.4, "Morocco": 3.1, "Tunisia": 0.4, "Egypt": 4.2}

for country, growth in countries.items():
    if growth > 3:
        status = "Strong / قوي"
    elif growth > 1:
        status = "Moderate / معتدل"
    else:
        status = "Weak / ضعيف"
    print(f"{country:10} {growth:+.1f}%  →  {status}")

6. Functions / الدوال

A function is a reusable block of code. Define it once with def, call it many times. Functions make your notebooks cleaner and avoid repeating code.

الدالة هي وحدة شيفرة برمجية قابلة لإعادة الاستخدام. تُعرَّف مرة واحدة بالكلمة المفتاحية def، ثم يمكن استدعاؤها عدة مرات. استخدام الدوال يجعل الشيفرة أكثر تنظيماً ويتجنب تكرار المنطق البرمجي.
# Basic function / دالة أساسية
def gdp_growth(gdp_old, gdp_new):
    """Calculate GDP growth rate / حساب معدل نمو الناتج"""
    return ((gdp_new - gdp_old) / gdp_old) * 100

# Call the function / استدعاء الدالة
print(gdp_growth(24500, 25100))  # → 2.2449...
print(gdp_growth(13200, 13600))  # → 3.0303...

# Function with default parameter / دالة بمعامل افتراضي
def classify_growth(rate, strong=5.0, moderate=2.0):
    if rate >= strong:
        return "Strong / قوي"
    elif rate >= moderate:
        return "Moderate / معتدل"
    elif rate > 0:
        return "Slow / بطيء"
    else:
        return "Recession / ركود"

print(classify_growth(2.4))   # → Moderate
print(classify_growth(6.1))   # → Strong
print(classify_growth(-1.2))  # → Recession

# Lambda (short one-line function) / دالة لامدا (سطر واحد)
inflation_real = lambda nominal, inflation: nominal - inflation
print(inflation_real(5.0, 2.4))  # → 2.6 (real rate)
