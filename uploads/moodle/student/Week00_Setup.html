Overview / نظرة عامة

This guide helps you set up your Python environment before Week 1. You have two options: Google Colab (browser-based, no installation) or a local setup with VS Code + Python + Jupyter.

يهدف هذا الدليل إلى مساعدتك على تهيئة بيئة العمل البرمجية قبل انطلاق الأسبوع الأول. لديك خياران: Google Colab (يعمل عبر المتصفح دون تثبيت) أو بيئة محلية باستخدام VS Code + Python + Jupyter.

Option A Google Colab (No Installation / بدون تثبيت)

Google Colab Recommended for beginners

Free, runs in your browser, no installation needed. All required libraries (pandas, numpy, matplotlib, seaborn, statsmodels, scikit-learn) are pre-installed.

مجاني ومتاح عبر المتصفح دون أي تثبيت مسبق. جميع المكتبات البرمجية المطلوبة مُثبَّتة افتراضياً في البيئة.
انتقل إلى colab.research.google.com وسجّل الدخول بحسابك على Google / Go to colab.research.google.com and sign in with your Google account
انقر File → Upload notebook واختر ملف دفتر جوبيتر .ipynb الذي نزّلته من المنصة / Click File → Upload notebook → select the .ipynb starter file
ارفع ملف البيانات: انقر أيقونة المجلد في الشريط الجانبي الأيسر → Upload → اختر algeria_economic_combined.csv / Upload the dataset: click the folder icon in the left sidebar → Upload
نفِّذ الخلايا البرمجية بـ Shift+Enter (تنفيذ والانتقال للتالية) أو Ctrl+Enter (تنفيذ الخلية الحالية) / Run cells: Shift+Enter (run & move) or Ctrl+Enter (run in place)
احفظ عملك في Google Drive: File → Save a copy in Drive / Save to Google Drive: File → Save a copy in Drive

Option B VS Code + Python + Jupyter (Local / محلي)

VS Code + Python + Jupyter

A full local development environment. VS Code is a free code editor that supports .ipynb notebooks natively via the Jupyter extension.

بيئة تطوير محلية متكاملة. VS Code محرر شيفرة مجاني يدعم دفاتر جوبيتر .ipynb مباشرةً عبر الإضافة الرسمية لـ Jupyter.

Step 1 — Install Python / تثبيت بايثون

انتقل إلى python.org/downloads ونزّل Python 3.11 أو أحدث / Go to python.org/downloads and download Python 3.11 or later
شغِّل المثبِّت — تأكد من تفعيل خيار "Add Python to PATH" قبل النقر على Install / Run the installer — check "Add Python to PATH" before clicking Install
تحقق من التثبيت: افتح Terminal (أو Command Prompt) ونفِّذ python --version / Verify: open Terminal and run python --version

Step 2 — Install VS Code / تثبيت VS Code

نزّل VS Code من code.visualstudio.com وثبِّته بالإعدادات الافتراضية / Download VS Code from code.visualstudio.com and install with default settings
افتح VS Code → انقر أيقونة الإضافات في الشريط الجانبي (أو Ctrl+Shift+X) / Open VS Code → click the Extensions icon (Ctrl+Shift+X)
ابحث عن Python (من Microsoft) وثبِّته / Search for Python (by Microsoft) and install it
ابحث عن Jupyter (من Microsoft) وثبِّته — يُتيح فتح ملفات .ipynb مباشرةً / Search for Jupyter (by Microsoft) and install it — enables opening .ipynb files directly

Step 3 — Install Required Libraries / تثبيت المكتبات

Open Terminal in VS Code (Ctrl+`) and run: / افتح الطرفية في VS Code (Ctrl+`) ونفِّذ:

pip install pandas numpy matplotlib seaborn statsmodels scikit-learn scipy
If pip is not recognized, use: python -m pip install pandas numpy matplotlib seaborn statsmodels scikit-learn scipy

Step 4 — Open a Notebook / فتح دفتر جوبيتر

في VS Code: File → Open Folder وانتقل إلى مجلد مشروعك الذي يحتوي على ملفات .ipynb وملفات CSV / In VS Code: File → Open Folder → navigate to your project folder containing .ipynb and CSV files
انقر نقرًا مزدوجاً على ملف .ipynb ليفتح في واجهة دفتر جوبيتر داخل VS Code / Double-click the .ipynb file — it opens as a Jupyter notebook inside VS Code
اختر مُفسِّر بايثون: انقر Select Kernel (أعلى اليمين) → اختر بيئة Python المثبَّتة / Select kernel: click Select Kernel (top right) → choose your installed Python
نفِّذ الخلايا بـ Shift+Enter أو بالنقر على زر التشغيل بجانب كل خلية / Run cells with Shift+Enter or click the play button next to each cell
Important / مهم: Place your CSV files (algeria_economic_combined.csv, world_bank_economic_indicators.csv) in the same folder as your .ipynb notebook. Otherwise you will get a FileNotFoundError.
ضع ملفات البيانات بصيغة CSV في نفس مجلد دفتر جوبيتر، وإلا ستظهر رسالة الخطأ FileNotFoundError.

Common Errors / الأخطاء البرمجية الشائعة
FileNotFoundError: algeria_economic_combined.csv
ملف البيانات CSV غير موجود في نفس مجلد الدفتر. في Colab: أعد رفع الملف عبر أيقونة المجلد. في VS Code: ضع ملف CSV في نفس مجلد .ipynb / In Colab: re-upload via the folder icon. In VS Code: place the CSV in the same folder as your notebook.
ModuleNotFoundError: No module named 'statsmodels'
المكتبة غير مثبَّتة. في VS Code Terminal: pip install statsmodels. في Colab، نفِّذ في خلية جديدة: !pip install statsmodels / In VS Code terminal: pip install statsmodels. In Colab cell: !pip install statsmodels
NameError: name 'df' is not defined
تجاوزت خلية برمجية سابقة. نفِّذ جميع الخلايا من البداية. في VS Code: Run All من قائمة الخلايا. في Colab: Runtime → Run all / Run all cells from top. In VS Code: click Run All. In Colab: Runtime → Run all
ValueError: could not convert string to float
عمود يحتوي على نصوص مختلطة بأرقام. تحقق بـ df.dtypes وعالج بـ pd.to_numeric(df['col'], errors='coerce') / A column contains text mixed with numbers. Check with df.dtypes, fix with pd.to_numeric()
KeyError: 'GDP_Growth'
اسم العمود غير مطابق تماماً (الأسماء حساسة لحالة الأحرف). تحقق من الأسماء الدقيقة بـ df.columns.tolist() / Column name mismatch — names are case-sensitive. Check exact names with df.columns.tolist()
VS Code: "Select Kernel" — no Python environment found
VS Code لا يرى بيئة بايثون. تأكد من تثبيت Python وإضافة Python من Microsoft. انقر Select Kernel → Install suggested extensions أو أعد تشغيل VS Code / VS Code cannot find Python. Make sure Python is installed and the Python extension is active. Click Select Kernel → Install suggested extensions or restart VS Code.
