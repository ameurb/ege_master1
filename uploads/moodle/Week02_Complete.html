Course / الدرس Week 2 — Lists, Dicts, Loops, Conditions

1. Lists / القوائم

An ordered, mutable collection of values. Use for sequences of data (inflation series, GDP over years).

مجموعة مرتّبة وقابلة للتعديل. استخدمها لتسلسلات البيانات (سلاسل التضخم، الناتج المحلي عبر السنوات).
inflation = [4.8, 6.4, 5.6, 4.3, 2.0, 9.2]   # list of floats

# Access / الوصول
print(inflation[0])      # → 4.8  (first / أول)
print(inflation[-1])     # → 9.2  (last / آخر)

# Operations / العمليات
inflation.append(5.5)    # add element / إضافة
len(inflation)           # → 7
sum(inflation)           # → 41.3
max(inflation)           # → 9.2
min(inflation)           # → 2.0
sorted(inflation)        # → [2.0, 4.3, 4.8, 5.5, 5.6, 6.4, 9.2]

2. Dictionaries / القواميس

Key-value pairs. Use for labeled data (country → GDP, indicator → value).

أزواج مفتاح-قيمة. استخدمها للبيانات المُصنَّفة (الدولة → الناتج المحلي، المؤشر → القيمة).
gdp = {"Algeria": 25100, "Morocco": 13200, "Tunisia": 4800}

# Access / الوصول
gdp["Algeria"]        # → 25100
gdp.keys()            # → dict_keys(['Algeria', 'Morocco', 'Tunisia'])
gdp.values()          # → dict_values([25100, 13200, 4800])
gdp.items()           # → pairs of (key, value)

# Add / إضافة
gdp["Egypt"] = 38000

# Loop / حلقة
for country, value in gdp.items():
    print(f"{country}: {value:,} B DZD")

3. For Loops / حلقات for

تُستخدم لتكرار عملية على كل عنصر في قائمة أو قاموس.
# Loop over list
years = [2020, 2021, 2022, 2023, 2024]
for year in years:
    print(f"Year: {year}")

# Loop with range
for i in range(5):       # 0, 1, 2, 3, 4
    print(i)

# Loop over dict
for country, gdp_val in gdp.items():
    print(f"{country}: {gdp_val}")

4. Conditions / الشروط

تُستخدم لاتخاذ قرارات بناءً على قيمة متغير.
growth_rate = 2.27   # Algeria 2024

if growth_rate > 5:
    print("Strong growth / نمو قوي")
elif growth_rate > 2:
    print("Moderate growth / نمو معتدل")
elif growth_rate > 0:
    print("Slow growth / نمو بطيء")
else:
    print("Recession / ركود")

5. Combining: Loop + Condition / دمج الحلقة مع الشرط

countries = {"Algeria": 2.4, "Morocco": 3.1, "Tunisia": 0.4, "Egypt": 4.2}

for country, growth in countries.items():
    if growth > 3:
        status = "Strong / قوي"
    elif growth > 1:
        status = "Moderate / معتدل"
    else:
        status = "Weak / ضعيف"
    print(f"{country:10} {growth:+.1f}%  →  {status}")
