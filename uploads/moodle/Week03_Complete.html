Course / الدرس Week 3 — Pandas Essentials

1. Import & Load / الاستيراد والتحميل

import pandas as pd

df = pd.read_csv('algeria_economic_combined.csv')
print(df.shape)          # → (rows, columns)
print(df.columns.tolist())
df.head(5)               # first 5 rows
df.info()                # dtypes + non-null counts

2. Explore / الاستكشاف

CommandWhat it does / ما تفعله
df.shapeRows × Columns / الصفوف × الأعمدة
df.head(n)First n rows / أول n صفوف
df.tail(n)Last n rows / آخر n صفوف
df.dtypesType of each column / نوع كل عمود
df.describe()Count, mean, std, min, max / الإحصاء الوصفي
df.isnull().sum()Count missing per column / القيم المفقودة

3. Select & Filter / الاختيار والتصفية

# Select column / اختيار عمود
df['GDP_Growth_Percent']
df[['Year', 'GDP_Growth_Percent', 'Inflation_Percent']]

# Filter rows / تصفية الصفوف
df[df['GDP_Growth_Percent'] > 3]           # growth above 3%
df[df['Year'] >= 2010]                      # since 2010
df[(df['GDP_Growth_Percent'] > 2) & (df['Inflation_Percent'] < 5)]

4. Aggregation / التجميع

df['GDP_Growth_Percent'].mean()     # average
df['Inflation_Percent'].max()       # maximum
df['Unemployment_Rate'].median()    # median

# Group by country
df.groupby('Country')['GDP_Growth'].mean()

# Year with max inflation
df.loc[df['Inflation_Percent'].idxmax(), 'Year']

5. Missing Values / القيم المفقودة

df.isnull().sum()           # count missing
df.dropna()                 # drop rows with any missing
df.fillna(df.mean())        # fill with column mean
df.ffill()                  # forward fill (pandas 2.x+)

6. Correlation / الارتباط

df[['GDP_Growth_Percent','Inflation_Percent','Unemployment_Rate']].corr()
# Interpretation: 1=perfect positive, -1=perfect negative, 0=no relation
# التفسير: 1=ارتباط موجب تام، -1=ارتباط سالب تام، 0=لا ارتباط

7. NumPy Essentials / أساسيات NumPy

NumPy هي مكتبة الحساب الرقمي في Python. تستخدمها pandas وmatplotlib وscikit-learn داخلياً — معرفتها ضرورية لأي تحليل بيانات.
import numpy as np

# Arrays / المصفوفات
gdp_values = np.array([24500, 25100, 26800, 27400])
print(gdp_values.mean())    # → average
print(gdp_values.std())     # → standard deviation / الانحراف المعياري
print(gdp_values.min(), gdp_values.max())

# Math operations (applied element-wise) / عمليات رياضية على كل عنصر
rates = np.array([0.024, 0.032, 0.028, 0.041])
growth_index = (1 + rates).cumprod()    # cumulative growth / النمو التراكمي
print(growth_index.round(4))

# Useful functions / دوال مفيدة
np.sqrt(49)         # → 7.0   (square root / الجذر التربيعي)
np.log(100)         # → 4.605 (natural log / اللوغاريتم الطبيعي)
np.abs(-3.5)        # → 3.5   (absolute value / القيمة المطلقة)

# From pandas column to numpy array
arr = df['GDP_Growth_Percent'].to_numpy()
print(np.percentile(arr, [25, 50, 75]))  # quartiles / الربيعيات
FunctionPurpose / الغرض
np.array([...])Create array / إنشاء مصفوفة
np.sqrt(x)Square root / الجذر التربيعي
np.log(x)Natural logarithm / اللوغاريتم الطبيعي
np.abs(x)Absolute value / القيمة المطلقة
np.mean(arr)Mean / المتوسط
np.std(arr)Standard deviation / الانحراف المعياري
np.percentile(arr, q)Percentile / الشريحة المئوية
