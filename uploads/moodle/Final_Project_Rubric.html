A. Data Preparation / تحضير البيانات
1. Data Loading & Cleaning
تحميل البيانات وتنظيفها
 5
5 ptsFile loaded correctly. All missing values handled with clear justification. Correct dtypes verified. Dataset shape and columns shown.
3–4 ptsFile loaded. Missing values handled but justification weak. Minor dtype issues.
2 ptsFile loaded. Missing values acknowledged but not properly handled.
0–1 ptsFile not loaded or major errors. No handling of missing values.
B. Analysis / التحليل
2. Descriptive Statistics
الإحصاء الوصفي
 4
4 ptsdescribe() shown for all numeric columns. Mean, median, std computed and compared. Skewness discussed.
3 ptsdescribe() shown. Key statistics computed but not all compared.
2 ptsOnly basic mean/max computed. No describe() table.
0–1 ptsNo statistics computed.
3. Statistical Analysis
التحليل الإحصائي
 4
4 ptsCorrelation matrix computed and plotted. OLS regression or ML model trained. R², coefficients, p-values correctly reported.
3 ptsCorrelation computed. Regression run but results not fully interpreted.
2 ptsOnly correlations between 2 variables. No regression.
0–1 ptsNo statistical analysis.
C. Visualizations / التمثيل البياني
4. Chart Quality
جودة المخططات
 4
4 pts4+ charts. Each has title, labeled axes, legend. Appropriate chart type chosen. Clean, readable layout. Saved as PNG.
3 pts3–4 charts. Most have titles and labels. Minor formatting issues.
2 pts2 charts. Missing titles or labels on some. Chart type sometimes inappropriate.
0–1 pts1 chart or no charts. Missing labels.
5. Chart Variety
تنوع أنواع المخططات
 3
3 ptsUses 3+ different chart types (line, bar, scatter, histogram, heatmap…) each well-suited to the data shown.
2 pts2 different chart types. Generally appropriate.
1 ptOnly 1 chart type used throughout.
0 ptsNo variety or charts missing.
D. Written Interpretation / التفسير المكتوب
6. Economic Interpretation
التفسير الاقتصادي
 5
5 ptsEach chart and result has 2–3 sentence interpretation. Interpretation is economically meaningful, references real context (Algeria, MENA…). Draws conclusions supported by data.
3–4 ptsMost results interpreted. Some interpretations are shallow or generic.
2 ptsInterpretations are present but mostly describe the data rather than interpreting it economically.
0–1 ptsNo interpretation or only 1 comment.
E. Presentation / العرض الشفهي
7. Oral Presentation
العرض الشفهي
 5
5 ptsClear structure (intro → analysis → conclusion). Both partners speak. Key results explained clearly. Handles Q&A well. Stays within 10 min.
3–4 ptsGood structure. Some results unclear. Minor time issues.
2 ptsOne partner does most of the talking. Results presented but not explained. Over/under time.
0–1 ptsNo clear structure. Cannot explain the work. Did not present.
