Quiz / الاختبار Week 8 — 10 Comprehensive Review Questions
Q1. df.describe() shows which statistics? ماذا تُظهر describe()؟
→ count, mean, std, min, 25%, 50%, 75%, max for each numeric column
Q2. How do you create a 2×2 grid of subplots? كيف تنشئ شبكة 2×2؟
→ fig, axes = plt.subplots(2, 2, figsize=(12, 8))
Q3. df[df['GDP'] > 3] — what does this do? ماذا تفعل هذه الشيفرة؟
→ Filters rows where GDP column value is greater than 3 / تُصفّي الصفوف التي تكون فيها قيمة GDP أكبر من 3
Q4. OLS result: coef = -0.45, p = 0.02 for Inflation. Interpretation? كيف تفسّر هذه النتيجة؟
→ A 1% increase in inflation is associated with a 0.45% decrease in GDP growth, and this effect is statistically significant (p < 0.05)
Q5. What is the difference between MAE and RMSE? ما الفرق بين MAE وRMSE؟
→ MAE treats all errors equally; RMSE squares errors, so large errors are penalized more / MAE يعطي أهمية متساوية لكل الأخطاء؛ RMSE يعاقب الأخطاء الكبيرة أكثر
Q6. How to handle missing values by replacing with column mean? كيف تعالج القيم المفقودة بالمتوسط؟
→ df.fillna(df.mean())
Q7. Best chart type to show a relationship between 2 numeric variables? أفضل مخطط لإظهار العلاقة بين متغيرَين كميَّين؟
→ Scatter plot / مخطط التشتت
Q8. What does random_state=42 ensure in train_test_split? ماذا يضمن random_state=42؟
→ Reproducible split — same division of data every run / نفس التقسيم في كل مرة يُشغَّل الكود
Q9. df.groupby('Country')['GDP'].mean() — what does this compute? ماذا تحسب هذه الشيفرة؟
→ Average GDP for each country group / متوسط الناتج المحلي لكل دولة
Q10. Name 3 metrics used to evaluate a regression model. سمّ 3 مقاييس لتقييم نموذج الانحدار.
→ R² (coefficient of determination), MAE (mean absolute error), RMSE (root mean squared error)
