Project / المشروع Description & Objectives

EN: Working in pairs (binomes), students will perform a complete economic data analysis using Python. The project integrates all course skills: data loading, cleaning, descriptive statistics, visualization, OLS regression, and (optionally) a machine learning model.

يعمل الطلاب في مجموعات ثنائية لإجراء تحليل اقتصادي كمّي متكامل باستخدام بايثون. يوظِّف المشروع جميع الكفاءات المكتسبة خلال المقياس: تحميل البيانات وتنظيفها، الإحصاء الوصفي، التمثيل البياني، الانحدار بطريقة المربعات الصغرى العادية (OLS)، ونموذج التعلم الآلي بصفة اختيارية.

Course / الدرس Project Structure Guide

Required Notebook Structure / هيكل دفتر جوبيتر المطلوب

  1. Introduction / المقدمة — أسماء أعضاء المجموعة، وصف مجموعة البيانات، إشكالية البحث (بالعربية والإنجليزية)
  2. Data Loading & Cleaning / تحميل البيانات وتنظيفها — read_csv، shape، dtypes، معالجة القيم المفقودة (isnull، fillna أو dropna)
  3. Descriptive Statistics / الإحصاء الوصفي — describe()، الوسط الحسابي والانحراف المعياري والوسيط للمتغيرات الرئيسية، معامل الالتواء
  4. Visualizations / التمثيل البياني — 4 أشكال بيانية كحد أدنى: مخطط خطي، عمودي، انتشار، مدرّج تكراري (أو خريطة حرارية). يجب أن يتضمن كل شكل عنواناً وتسميات للمحاور وفقرة تفسيرية اقتصادية.
  5. Statistical Analysis / التحليل الإحصائي — مصفوفة الارتباط والخريطة الحرارية. انحدار OLS: صياغة الفرضية، تشغيل النموذج، تفسير معامل التحديد R² ومعاملَين ذوَي دلالة إحصائية، تشخيص البواقي.
  6. Conclusion / الخلاصة والاستنتاجات — 3 استنتاجات اقتصادية مستخلَصة من التحليل، حدود الدراسة، التوسعات الممكنة.
  7. [Bonus] ML Model / [اختياري] نموذج التعلم الآلي — تقسيم مجموعتَي التدريب والاختبار، انحدار خطي أو غابة عشوائية، الإبلاغ عن R²/MAE/RMSE، مخطط القيم الفعلية مقابل المتنبَّأ بها.
هيكل دفتر جوبيتر: 1-المقدمة وإشكالية البحث 2-تحميل البيانات وتنظيفها 3-مقاييس الإحصاء الوصفي 4-الأشكال البيانية (4 كحد أدنى) 5-التحليل الإحصائي (مصفوفة الارتباط + انحدار OLS) 6-الخلاصة والاستنتاجات الاقتصادية 7-[اختياري] نموذج التعلم الآلي

Activity / النشاط Session 7 — Project Work & Checkpoint

In-class Milestone / نقطة تقدّم في القاعة

  • Dataset loaded and cleaned — show df.shape and isnull().sum()
  • Research question defined (written as markdown cell in notebook)
  • At least 2 charts drafted
  • Correlation matrix computed
للحصة السابعة: أظهر تحميل البيانات وتنظيفها، صياغة إشكالية البحث، شكل بياني أو اثنين، ومصفوفة الارتباط — يُسجَّل كتقدّم أوّلي في المشروع.

Presentation Tips / نصائح العرض الشفهي

  • Structure: Introduction (1 min) → Data & Methods (2 min) → Results & Charts (4 min) → Conclusion (2 min) → Q&A (1 min)
  • Both partners must speak — split the sections equally / كلا الطالبين يتكلمان — قسّما الأقسام بالتساوي
  • Use the dashboard PNG as your main visual / استخدما صورة لوحة البيانات كوسيلة بصرية رئيسية
  • Economic language: use terms like "statistically significant", "positive correlation", "R² explains…" / استخدما المصطلحات الاقتصادية

Submission Checklist / قائمة التسليم

  • Jupyter Notebook (.ipynb) — runs without errors, all cells executed / يعمل بدون أخطاء، جميع الخلايا منفّذة
  • PDF Report (3–5 pages) — includes charts, interpretations, conclusion / يتضمن المخططات والتفسيرات والخلاصة
  • Dashboard PNG — exported from notebook / مصدَّرة من الدفتر
  • Both files uploaded to Moodle before deadline / كلا الملفين مرفوعان على Moodle قبل الموعد
  • In-class presentation delivered / العرض الشفهي في القاعة

Q5. What earns the bonus 3 points? ما الذي يُكسب نقاط المكافأة الـ3؟
→ A working ML model (LinearRegression or RandomForest) with R², MAE, RMSE reported and actual vs predicted plotted

→ 10 minutes maximum — both partners must speak / 10 دقائق كحد أقصى — كلا الطالبين يتكلمان
